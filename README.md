# Villi kopparin päiväkirja

Puhelimelle ja tietokoneelle sopiva mönkijän ajopäiväkirjan selainversio.

## Julkaisu GitHub Pagesilla

1. Luo GitHubissa uusi repository, esimerkiksi `villi-kopparin-paivakirja`.
2. Lataa tämän paketin `index.html` repositoryn juureen.
3. Avaa repositoryn **Settings → Pages**.
4. Valitse **Deploy from a branch**.
5. Valitse `main` ja `/ (root)` ja tallenna.
6. GitHub antaa sivulle oman `github.io`-osoitteen.

Huom: tämä ensimmäinen versio tallentaa tiedot selaimen paikalliseen muistiin. Jos haluat saman datan näkyviin kaikilla laitteilla, seuraavassa vaiheessa tarvitaan verkkotietokanta ja kirjautuminen.
